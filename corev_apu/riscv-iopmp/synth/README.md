# Guide to Run the Synthesis

To run the synthesis for the five configurations, follow the steps below:

1. **Open a terminal** and navigate to the `synth/` folder.
   
   If you're in the root directory of the project:
   ```bash
   cd synth

2. Run the synthesis script by using the make command:

   ```bash
   make run_synthesis

Make sure that the 'cshrc' file is located in the same directory where you cloned the project repository.
